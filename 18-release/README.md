# 第 18 章：系统集成与发布验收

状态：规划中，尚无可运行实现。

## Workflow 目标

将已验证的单任务闭环整合为一个可安装、可配置、可交接的 Rust CLI。明确支持的平台、CLI 版本、信任边界及升级方式。Hermes 不属于本章依赖或交付条件。

## 验收计划

- 从干净环境按运行手册安装并完成一个受控任务。
- 配置校验、候选提交、验证日志、审查结果和终态可追溯。
- 取消、超时、重启及人工接手通过端到端检查。
- 交付运行手册、排障步骤、支持范围及已知限制。
- 明确产物保留和清理策略；不丢失未集成候选或未保存改动。

具体命令和发布方式在实现时补充。生产就绪声明必须对应实际验收记录，不由章节完成数量决定。

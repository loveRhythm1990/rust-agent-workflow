# 第 1 章 Rust 配套：变量、输出与函数

本章对应 [src/main.rs](src/main.rs)。先运行示例，再对照下面的语法阅读代码。

## 函数与入口

```rust
fn main() {
    print_learning_goal();
}

fn print_learning_goal() {
    println!("学习目标：用 Rust 构建可验证的多 Agent 协作工具");
}
```

`fn` 定义函数，括号是参数列表，花括号是函数体。`main` 是可执行程序的入口。调用函数写函数名与括号；即使没有参数也要保留括号。这里的函数没有显式返回值类型，返回单元类型 `()`。

## 变量与类型推断

```rust
let project_name = "rust-agent-workflow";
let chapter = 1;
```

`let` 创建绑定。字符串字面量这里是 `&str`，整数这里推断为 `i32`。也可以明确写 `let chapter: i32 = 1;`。`&str` 的借用含义将在第二章展开，本章无需使用拥有堆分配的 `String`。

变量默认不可变。需要重新赋值时写：

```rust
let mut chapter = 1;
chapter = 2;
println!("第 {} 章", chapter);
```

给未声明 `mut` 的变量赋新值会产生编译错误。另一个 `let chapter = 2;` 则是创建新绑定，称为遮蔽；它与修改原变量不是同一操作。

## 格式化输出

```rust
println!("项目：{}", project_name);
println!("第 {} 章：Cargo 与第一个程序", chapter);
```

`println!` 是宏，感叹号是宏调用语法的一部分。`{}` 是占位符，参数按顺序填入。末尾自动换行。占位符需要对应参数，漏传参数会在编译时被指出。

## 语句、表达式与注释

本章用分号结束 `let`、输出和函数调用语句。Rust 的表达式也可产生值，例如函数体末尾的 `1 + 1` 可作为返回值；后续章节再结合实际函数说明。

`//` 后面的内容是行注释，不参与程序执行。注释应解释意图，代码本身表达操作。

## 遇到错误时怎么读

先运行 `cargo check -p chapter-01-cargo`，看报错指出的文件和行号，再阅读原因与建议。一次只改一个问题并重新检查。`cargo fmt --all` 统一排版，但不能修复类型或行为错误。

## 小练习

1. 将项目名保存到一个新变量并打印它。
2. 将章节变量声明为 `i32`，确认输出不变。
3. 尝试不可变变量重新赋值，观察报错后改为 `mut`。
4. 添加一个无参数函数并从 main 调用，打印下一章名称。

这些练习修改本章程序即可，无需添加第三方库。完成后运行检查与程序，分别验证编译和输出。
